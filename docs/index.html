把一台 Mac 的 VPN
共享给整个 Wi-Fi。 One Mac's VPN,
shared to the whole Wi-Fi.

Conduit 由两个 macOS 桌面应用组成。Server 在持有 VPN 的那台 Mac 上跑 HTTP / SOCKS5 + mDNS， Client 在其它设备上自动发现、5 步连接、自动切换系统代理。零配置，零路由器修改。 Conduit ships as two macOS desktop apps. Server exposes HTTP / SOCKS5 with mDNS, Client auto-discovers, connects in 5 steps and switches the system proxy. Zero config, no router tweaks.

架构Architecture

三层栈，进程隔离。 Three layers. Process-isolated.

Tauri 主进程负责窗口与托盘，Vue 控制台只画 UI，所有网络逻辑跑在独立的 Python Sidecar 里 —— localhost HTTP + SSE 通信。 Tauri owns the window & tray. Vue only renders. All networking lives in an isolated Python sidecar — talking over localhost HTTP + SSE.

未签名 + 暂未公证 —— 一行命令补救 Unsigned & not-yet-notarized — one-line fix

DMG 是 ad-hoc 签名、Apple 公证还在路上。第一次打开会被提示「已损坏」或「无法验证开发者」—— 跑下面一行命令即可解决。 DMGs are ad-hoc signed, Apple notarization is pending. First launch shows "damaged" or "cannot be verified" — the one-liner below fixes it.

移除 quarantine 属性 Strip the quarantine attribute

推荐Recommended

把 .app 拖进 /Applications 后，跑下面两行命令。之后双击就能正常打开，每次重新下载或替换 .app 再跑一次即可。 Drag the .app into /Applications, then run the two lines below. Double-click works afterwards. Re-run after any re-download. 

xattr -dr com.apple.quarantine "/Applications/Conduit Server.app"
xattr -dr com.apple.quarantine "/Applications/Conduit Client.app"
