把一台 Mac 的 VPN
共享给整个 Wi-Fi。 One Mac's VPN,
shared to the whole Wi-Fi.

Conduit 由两个 macOS 桌面应用组成。Server 在持有 VPN 的那台 Mac 上跑 HTTP / SOCKS5 + mDNS， Client 在其它设备上自动发现、5 步连接、自动切换系统代理。零配置，零路由器修改。 Conduit ships as two macOS desktop apps. Server exposes HTTP / SOCKS5 with mDNS, Client auto-discovers, connects in 5 steps and switches the system proxy. Zero config, no router tweaks.

Conduit Server

装在持有 VPN 的那台 Mac 上。同时开 HTTP / SOCKS5 代理 + mDNS 广播。 Runs on the Mac that holds your VPN. Exposes HTTP / SOCKS5 with mDNS.

Conduit Client

装在每一台想用共享 VPN 的设备上。自动发现，5 步连接，切系统代理。 Runs on every device that wants the shared VPN. Auto-discover, 5-step connect, system-proxy switch.
