## 0. 设计语言（约束基线）

### 0.1 整体配色

| 用途 | 色值 | 在 ASCII 里的标记 |
|---|---|---|
| 主色（标题栏 / 主按钮 / 强调） | 深空蓝 `#1B2A4E` | `█` 或 `■` |
| 强调色（流光 / 数据高亮） | 流体青 `#00D4FF` | `▲` `↑` `↓` |
| 健康 / 成功 | 绿 `#10B981` | `🟢` 或 `●` |
| 警告 / 异常 | 黄 `#F59E0B` | `🟡` 或 `▲` |
| 错误 / 断开 | 红 `#EF4444` | `🔴` 或 `●` |
| 中性 / 未启动 | 灰 `#6B7280` | `⚪` 或 `○` |

### 0.2 字号与间距

```
标题栏：     18px / 600 weight
区块标题：   16px / 600 weight
正文：       14px / 400 weight
辅助文字：   12px / 400 weight (灰)
等宽：       14px (流量数字、IP、端口)

外边距：     窗口边缘 24px
区块间距：   20px
卡片内边距： 16px
```

### 0.3 状态徽章规范

```
[● 运行中]   绿底白字       [○ 未启动]  灰底深字
[▲ 警告]     黄底深字        [● 已断开]  红底白字
[● 连接中]   蓝底白字（脉冲） [● 自动直连] 橘底白字（fallback 后）
```

### 0.4 通用窗口框架（ASCII 模板）

#### Server App — 左侧 Sidebar 布局

```
┌─ Conduit ────────────────────────────────────────────────────┐ ◀ 标题栏
│ <顶部状态栏：徽章 + 端口 + 主操作（启动/停止）>              │ ◀ 32px 高
├────────────┬─────────────────────────────────────────────────┤
│            │                                                 │
│ ◉ 仪表盘   │                                                 │
│ ☰ 日志    │   <主内容区>                                    │ ◀ 视图主体
│ ⚙ 设置    │                                                 │
│            │                                                 │
│            │                                                 │
└────────────┴─────────────────────────────────────────────────┘
   ▲              ▲
   200px sidebar  剩余宽度给主内容区
```

#### Client App — 无 sidebar，view 自动切换

```
┌─ Conduit Client ─────────────────────────────────────────┐ ◀ 标题栏
│ <顶部状态栏：徽章 + 当前 server + ⚙ 齿轮>               │ ◀ 32px 高
├──────────────────────────────────────────────────────────┤
│                                                          │
│   <主内容区根据连接状态自动切换>                         │
│                                                          │
│   未连接 ──▶ Discovery                                   │
│   连接中 ──▶ 进度面板                                    │
│   已连接 ──▶ Connected                                   │
│   异常   ──▶ 警告横幅 + Connected 降级显示              │
│                                                          │
├──────────────────────────────────────────────────────────┤
│            <底部主操作区：连接 / 断开 / 诊断>            │ ◀ 32px 高
└──────────────────────────────────────────────────────────┘
```

> **为什么 server-app 用 sidebar、client-app 不用？** Server-app 是"日常驻留型"应用，需要在仪表盘/日志/设置三个独立信息平面之间随时切换；Client-app 是"任务型"应用，主路径是发现 → 连接 → 用，不需要持久导航。

### 0.5 通用尺寸

| App | 默认窗口 | 最小窗口 | 备注 |
|---|---|---|---|
| server-app | 1200 × 720 | 900 × 600 | 含 200px sidebar + 流量图，需要更宽 |
| client-app | 720 × 540 | 640 × 480 | 信息密度低，紧凑 |

## 4. 关键交互细节

### 4.1 server-app 主导航：左侧 Sidebar

左侧 sidebar 是 **持久导航**（始终可见，宽度固定 200px），切换时**仅更换右侧主内容区**，顶部状态栏（徽章 + 端口 + 启动/停止按钮）不变。

```
┌────────────┐
│            │
│ ◉ 仪表盘   │  ◀ 当前选中：左侧蓝色竖条 + 实心圆点 + 高亮文字
│            │
│ ☰ 日志    │  ◀ 未选中：浅灰文字 + 空心图标
│            │
│ ⚙ 设置    │
│            │
└────────────┘
```

**视觉规范**：

- 选中态：背景 `bg-accent`、左侧 4px 竖条 `bg-primary`、图标实心、文字 600 weight
- 未选中态：背景透明、图标轮廓、文字 400 weight、`text-muted-foreground`
- Hover 态：背景 `bg-accent/50`，图标颜色加深
- 切换动画：100ms 淡入 + 主内容区 X 轴 5px 推入
- Sidebar 顶部留 16px 间距对齐标题栏底缘
- 三个 item 之间间距 4px

**为什么不用底部 Tab？**

1. server-app 是日常驻留型应用（VPN 共享会跑数小时），左侧 sidebar 与 macOS 系统 App（Reminders、Messages）一致
2. 横向空间充裕（窗口默认 1200px），sidebar 占用感低
3. 未来若新增 view（如"统计报表"），sidebar 是天然可扩展的列表

### 4.2 client-app 视图切换

client-app **不用持久 Tab**——主体根据连接状态自动切换 view（Discovery → Connected → Diagnostic），用户主动切换的只有 Settings（右上角齿轮 → 推 Settings 全屏 → 关闭 Settings 回到原 view）。

## 6. 实施约束（给前端工程师）

1. **所有图标用 lucide-vue-next**（与 server-app/ui 锁定的依赖一致），不引入额外 icon 包
2. **所有动画 ≤ 200ms**（脉冲、淡入、滑动），避免感觉卡
3. **所有 ASCII 框示意的 box** 实际用 `shadcn-vue/Card`（已在 shared-ui 暴露）
4. **所有按钮严格按 shadcn-vue/Button 的 size + variant 组合**：
   - 主操作（启动 / 连接 / 应用）：`size="default" variant="default"`（深空蓝填充）
   - 次操作（取消 / 关闭 / 返回）：`size="default" variant="outline"`
   - 危险操作（停止 / 断开 / 删除）：`size="default" variant="destructive"`
5. **暗色模式必须默认跟随系统**（`prefers-color-scheme: dark`）
6. **流量图严格用 uPlot**（设计文档锁定，~40KB），不上 ECharts/Chart.js
